# KanbanApi

KanbanApi es una API REST desarrollada con ASP.NET Core cuyo objetivo es proporcionar una plataforma de gestión y organización de tareas inspirada en herramientas como Trello.

La aplicación permite gestionar tareas, organizarlas y realizar un seguimiento de su estado a través de diferentes operaciones CRUD.

Actualmente, el proyecto se encuentra en fase de desarrollo y está centrado en la implementación del backend. La interfaz gráfica todavía no está implementada, por lo que la API se puede probar e interactuar con ella mediante Swagger.
